# **爆款生成指令**

**请以[书籍名称]为核心素材，创作一篇引发当代人共鸣的深度书评，严格遵循以下规则：**

#### **1. 选题定位**

```
▸ 核心冲突：
用书中一个被忽视的情节（如配角抉择/道具象征），揭露现代人面临的______问题（从职场内卷/社交虚伪/道德困境选填）
▸ 价值主张：
通过该情节传递「______＞______」的反共识结论（如真诚＞精明、善良＞功利）
```

#### **2. 开头设计**

```
█ 必含元素：
① 原著金句引用（示例：「人们宁愿去关心一个蹩脚演员的吃喝拉撒，也不愿了解普通人波涛汹涌的内心世界」）
② 当代现象对比（如：当我们在朋友圈表演精致时，书中XXX早已看破虚伪）
③ 灵魂发问（使用「为什么XX越…，我们越…？」句式）
```

#### **3. 主体结构**

```
>> 每章节必须包含：
❶ **原著场景复刻**（细节到气味/触感/声音，如「高粱面馍粗粝的触感划过喉管」）
❷ **人物选择分析**（对比功利VS真诚的决策差异）
❸ **现实事件映射**（2010年后新闻案例，如「杭州保姆纵火案揭示信任悖论」）
❹ **金句提炼**（使用「_____，才是_____的_____」句式，如「守拙，才是精明时代的生存智慧」）

>> 三幕剧节奏：
▫ 第1幕：展示原著困境（占比30%）
▫ 第2幕：揭露现实对照（占比50%，需含1个数据：如《2023职场社交报告》显示XX%人遭遇伪善）
▫ 第3幕：提出破局之道（占比20%，给出3条具体行动建议）
```

#### **4. 共情触发点**

```
█ 必须植入：
✓ 阶层痛点（用「月薪XX元VS房价XX万」量化对比）
✓ 年龄焦虑（「25岁/35岁/45岁」分阶段论述）
✓ 道德困境（设置「如果是你」选择情境，如：当同事甩锅时，做孙少安还是田福堂？）
```

#### **5. 传播设计**

```
█ 文末必须包含：
① 测试互动（「测测你是书中哪个角色」+ 虚拟选项）
② 转发话术（用「@子女/@下属/@闺蜜」等身份标签）
③ 宗教式标语（如：转发这个孙少平，下周客户对你掏心窝）
```

#### **6. 视觉标记**

```
█ 格式要求：
✓ 每200字插入「▌人性实验室▌」等符号标题
✓ 核心观点用**加粗**，矛盾点用_斜体_
✓ 在70%进度处插入「>> 今日思考 <<：XXX真的过时了吗？」
```
