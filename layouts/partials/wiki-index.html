{{- /* 全站双链索引：小写标题 + 小写别名 → RelPermalink。 无 variant 的 partialCached 保证全站只计算一次。 标题/别名冲突时用 errorf 让构建直接失败，不静默覆盖。 收录范围：params.linkSections 列出的所有双链分区（由 link-sections.html 读出）。 用 site.Pages 而不是 RegularPages —— 多收一个分区首页 content/
/_index.md， 这样 [[双链库]] 这类指向索引页的写法也能解析，否则页面明明存在却显示「未收录」。 新增双链分区只改 hugo.yaml 的 params.linkSections，不用动这个文件。 冲突判定规则：只有当「同一个键已被另一个页面占用」时才算冲突。 同一页面自己撞自己（例如 aliases 里写了与 title 相同的名字， 或两个别名互相同名）不是冲突 → 静默跳过，不报错。 兼容性：CI 固定 Hugo 0.130.0，本地是 0.145.0。0.130 下 where 结果里 .Title / 别名的静态类型是 interface{}：`strings.TrimSpace .` 会报 "can't evaluate field TrimSpace in type interface {}"，而 `lower .` 会静默返回空串（危险）。统一用 `lower (trim X " ")`，两版行为一致。 */ -}} {{- partial "wiki-meta-guard.html" . -}} {{- $m := dict -}} {{- $own := slice -}} {{- /* 本页已登记的键，用于区分「自指」与「跨页冲突」 */ -}} {{- $sections := partialCached "link-sections.html" . -}} {{- range where site.Pages "Section" "in" $sections -}} {{- $url := .RelPermalink -}} {{- $own = slice -}} {{- $key := lower (trim .Title " ") -}} {{- if $key -}} {{- $own = $own | append $key -}} {{- with index $m $key -}} {{- errorf "WIKI COLLISION: 标题 %q 同时被 %s 与 %s 占用" $key . $url -}} {{- end -}} {{- $m = merge $m (dict $key $url) -}} {{- end -}} {{- $aliases := .Params.aliases | default slice -}} {{- range $aliases -}} {{- $a := lower (trim . " ") -}} {{- if and $a (not (hasPrefix $a "/")) -}} {{- /* 别名与自身标题（或自身其它别名）重名：不算冲突，跳过 */ -}} {{- if in $own $a -}} {{- /* self-reference: ignore */ -}} {{- else -}} {{- with index $m $a -}} {{- errorf "WIKI COLLISION: 别名 %q 同时被 %s 与 %s 占用" $a . $url -}} {{- end -}} {{- $own = $own | append $a -}} {{- $m = merge $m (dict $a $url) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $m -}}
